При точной настройке исключений рекомендуется добавить исключение, но если вы не уверены в своих действиях, лучше отключить детектирование PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS)
    * В Chrome активируйте "Использовать безопасный DNS" и укажите поставщика услуг DNS, отличный от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в настройках системы - [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно

2. Загрузите zip/rar-архив с [последнего релиза](https://github.com/noblefreighterreduce/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг не требуется

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу или специальные символы

5. Запустите нужный файл
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для запуска стратегии вместе с системой выберите **`service.bat`** -> `Install Service` -> *подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) - ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) - автозапуск и дополнительные операции:
  - <ins>**`Install Service`** - добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** - удаление стратегии и WinDivert из списка служб
  - **`Check Status`** - просмотр состояния обхода и служб, включая автозапускаемую стратегию и WinDivert
  - **`Game Filter`** - изменение режима обхода для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После смены режима стратегию необходимо перезапустить.**  
  В скобках отображается текущее состояние: включено или выключено.
  - **`IPSet Filter`** - настройка режима обхода сервисов из `ipset-all.txt`.  
  Этот пункт полезен при проверке ресурса, который без zapret доступен, а с ним не работает.  
  В скобках показывается состояние:
    - `none` - IP-адреса не проходят проверку
    - `loaded` - IP проверяется на наличие в списке
    - `any` - под фильтр попадает любой IP  
  - **`Auto-Update Check`** - включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** - замена выбранного активного фейка на другой файл из каталога `bin`
  - **`Update IPSet List`** - получение актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** - обновление hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** - ручная проверка наличия обновлений
  - **`Run Diagnostics`** - поиск распространённых причин неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает при внезапной остановке работы приложения
  - **`Run Tests`** - проверка стратегий:
    - `Standard tests` - проверка сайтов, указанных в `utils/targets.txt`
    - `DPI checkers` - проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe (обход), заметный на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/noblefreighterreduce/zapret-discord-youtube/issues/522)

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не работает телеграм (веб версия)
Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts окажется устаревшим, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - От имени администратора откройте текстовым редактором файл `hosts` в появившейся папке
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленный аналогичный фрагмент
  - Сохраните файл и проверьте подключение ещё раз. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа не гарантирована. При отсутствии результата используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/noblefreighterreduce/tg-ws-proxy) либо любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем утрачивать работоспособность.**
> Вариант, который некоторое время работал, может перестать работать после его обнаружения.
> В репозитории собрано много стратегий обхода. Если ни одна не подходит, создайте новую на базе одного из существующих вариантов, изменив его параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте отсутствие ошибок

- Удостоверьтесь, что адрес нужного ресурса присутствует в списках доменов или IP

- Проверьте другие варианты, включая **`ALT`**, **`FAKE`** и остальные стратегии

- Выполните полную переустановку по инструкции ниже

- См. [#765](https://github.com/noblefreighterreduce/zapret-discord-youtube/issues/765)

### Как переустановить/обновить полностью?
- Сохраните добавленные вами ресурсы и данные
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их, затем в конце выберите Y
- Удалите каталог zapret
- Загрузите свежую версию на [странице релизов](https://github.com/noblefreighterreduce/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть флажок разблокировки, установите его, нажмите применить и ОК
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов
- По очереди запускайте разные скрипты `general` и проверяйте доступность интернет-ресурсов. Если вариант не работает, закройте программу через значок замка на панели задач и попробуйте другую стратегию
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Не работает игра/приложение с включённым запретом

- Убедитесь, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит ругается на WinDivert

- Инструкция доступна здесь - https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- Замените в [`bin`](./bin) файлы `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Переберите остальные стратегии, особенно если раньше всё работало
- См. также [#251](https://github.com/noblefreighterreduce/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fиспользование) включён
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord
- Проверьте приложение Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею
- Если Discord не открывается и в браузере, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах
- См. также [#252](https://github.com/noblefreighterreduce/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/noblefreighterreduce/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Наиболее универсальная последовательность действий:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не сработало, дополнительно включите `ipset any`

Учитывайте, что при `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Определите все IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если результата всё равно нет, создайте обсуждение в разделе [Discussions](https://github.com/noblefreighterreduce/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Сообщите о ней [здесь](https://github.com/noblefreighterreduce/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** - домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** - домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен этой сети фильтровать не нужно
- **`ipset-all.txt`** - IP-адреса и подсети
- **`ipset-exclude-user.txt`** - исключаемые IP-адреса и подсети
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
